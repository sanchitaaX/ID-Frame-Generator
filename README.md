# 🌊 HH Goa 2026 — 3D Frame & ID Card Generator (`#FrameInGoa`)

> **Task #1 Official Submission for Hacker House Goa 2026**  
> An ultra-premium, interactive 3D Photo Frame & ID Card Generator built for builders submitting for HH Goa 2026. Featuring realistic Three.js WebGL ocean shaders, procedural coconut palm trees, Auth0 3D card tilt physics, Codrops #2 depth laser scanner effects, teammate squad pass mode, and instant 1-click export to X.

---

## ✨ Features

- 🌊 **Realistic 3D Three.js Ocean Shader**: Custom WebGL vertex & fragment shaders calculating multi-harmonic wave physics, height-based turquoise water color blending, and golden sunset reflections.
- 🌴 **Procedural Coconut Palm Tree Generator**: Parametric geometry generator using trunk section tapering algorithms, Euler ring rotation math, curved leaf crown instancing, and ambient wind sway animation.
- 🎴 **Auth0 3D Parallax Tilt Card**: Real-time `rotate3d` perspective calculations with dynamic cursor-following radial light tracking and 3D depth layering.
- ⚡ **Codrops #2 Laser Scanning Depth Map FX**: Toggable scanning laser beam moving top-to-bottom across the ID pass with wireframe depth matrix grid overlay.
- 👥 **Multi-Member Squad Pass Mode**: Bring your teammates into a single, unified HH Goa 2026 frame! Supports 1 to 4 builders with auto-fit containers, custom roles, and X handles.
- 🧪 **Automated Builder Class Engine**: Smart algorithm mapping developer tech stacks (`Solana`, `Rust`, `AI Agents`, `ZK Proofs`, `DeFi`, etc.) to futuristic Builder Classes (*Solana Alchemist*, *AI Agent Mastermind*, *Rust Kernel Warlord*, *ZK Phantom*) with rarity tiers and hacker stats.
- 🎨 **Vibrant Colorful Goa Themes**: Choose between *Goa Sunset*, *Tropical Beach*, *Festive Fiesta*, and *Golden Sand* palettes.
- 🔊 **Web Audio API Sea Wave Ambience**: Zero-asset procedural ocean surf sound synthesizer and cyberpunk laser scan SFX with audio toggle.
- 📸 **1-Click HD PNG Export & Share to X**: Render crisp high-definition PNG passes with celebratory confetti and share directly to X (Twitter) using pre-filled `#FrameInGoa` hashtags.

## 🚀 Quick Start (Local Setup)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sanchitaaX/ID-Frame-Generator.git
   cd ID-Frame-Generator
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## 📸 Usage Guide (#FrameInGoa)

1. **Customize Identity**: Enter your name, X handle, and upload your builder photo.
2. **Select Stack & Roll Class**: Pick your tech stack tags to automatically generate your custom Builder Class & stats.
3. **Add Squad Teammates (Optional)**: Click **Add Teammate** to combine your team into one frame.
4. **Experience 3D Effects**: Hover over the card to feel the Auth0 3D tilt, or click **DEPTH SCAN** for laser matrix effects.
5. **Export & Post**: Click **1-Click HD Download** or **1-Click Share to X** with `#FrameInGoa` to get featured on the HH Goa Radar!
